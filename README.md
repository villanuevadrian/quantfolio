# QuantFolio

> A personal investment portfolio tracker with a quantitative analysis layer.
> Built with FastAPI, PostgreSQL and Docker.

## Status

🚧 In active development. Backend foundation complete (data model, repository
and service layers); API endpoints in progress.

## Overview

QuantFolio is a personal investment tracker that centralises positions held
across different brokers and platforms into a single view. Instead of checking
each broker separately, a user records their transactions and QuantFolio
consolidates them — showing holdings, returns and total net worth in one place.

It also includes an event manager to keep track of relevant dates for the
assets in a portfolio (earnings, dividends, personal reminders).

## Architecture

The backend follows a layered architecture with a strict separation of
concerns:

```
Request → Router → Service → Repository → Database
```

- **Router** — HTTP endpoints, request/response handling
- **Service** — business logic (validation, calculations, orchestration)
- **Repository** — database access (queries only, no logic)
- **Database** — PostgreSQL

Database access is confined to the repository layer, which keeps business
logic testable and independent of the persistence mechanism.

## Getting started

### Prerequisites
- Docker and Docker Compose

### Run locally
```bash
git clone git@github.com:villanuevadrian/quantfolio.git
cd quantfolio
cp .env.example .env   # then fill in your own values
docker compose up -d
```

The API is available at `http://localhost:8000`
Interactive API docs (auto-generated by FastAPI) at `http://localhost:8000/docs`

### Run the checks
```bash
pre-commit run --all-files   # ruff + mypy
```
